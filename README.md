bring back fun side projects

made a visualizer / media player using google mediapipe's machine learning models to track my thumb and index fingers 

tech stack: HTML, CSS, JavaScript, MediaPipe Tasks Vision, Canvas API, 98.css.

graphics: Windows 98-inspired interface using the open-source [98.css](https://jdan.github.io/98.css/) library. visuals are sourced from some visualizers that il update this readme for to give the proper links.

**Setup:** run `python -m http.server 8000`, and open `http://localhost:8000`. allow webcam access and click start. can also just do `npx serve` if you have that
